# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- MDX custom components for `Link` and `YouTube` embeds.
- Heading anchor links with copy functionality.
- Article sorting (Newest, Oldest, Shortest read, Longest read) in `/articles`.
- Smooth Framer Motion scroll animations for Hero and Article cards.
- Dynamic OpenGraph Image (`/api/og`) generation for articles.
- RSS Feed and GitHub repository links in the main Header.
- Keyboard shortcuts (`Cmd+K`) to focus and redirect to global search.
- Article Bookmarking (Save for Later) with `localStorage` and a dedicated `/saved` page.
- Native Next.js `<Image>` optimization configuration.
- Header dropdown menu to navigate categories.

### Changed
- Replaced standard `<a>` and `<img>` tags in MDX to utilize the new optimized components.
- Removed legacy articles, keeping only "NVIDIA Acquires Hugging Face" and "GMI MiniMaxthon 2026".
- Strict category alignment between content frontmatter and Header/Footer navigation.
- Replaced the Author Bio text to indicate content is generated by Mosaab's Agents.
- Updated default avatars to Mosaab's profile picture.
- Disabled `edge` runtime for API routes per modern Next.js recommendations.
- Reordered `RelatedArticles` section above the Newsletter in article layout.

### Fixed
- Fixed TypeScript `any` types in `next.config.ts` and `mdxComponents`.
- Fixed missing `lucide-react` Github icon by implementing a custom `GithubIcon` SVG.
- Handled hydration mismatches safely across Client Components utilizing `localStorage` and `useTheme`.
